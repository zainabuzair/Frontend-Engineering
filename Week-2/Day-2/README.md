# JavaScript Fundamentals & Logic Workshop

A comprehensive collection of fundamental JavaScript programming concepts, control flow patterns, function types, loop structures, and practical problem-solving implementations.


---

## 🔍 Overview

This repository demonstrates key JavaScript ES6+ foundational concepts designed for beginners and developers looking to refresh core logic building. It covers evaluation with logical operators, conditional branching via `if/else` and `switch` statements, standard and arrow functions, callback patterns, array iteration techniques, and practical programming challenges.

## 📚 Topics Covered

### 1. Control Flow & Branching
- **Logical Operators (`&&`, `||`, `!`):** Complex condition evaluation combining multiple criteria (e.g., checking score thresholds and membership status).
- **Switch Statements:** Clean control structures for direct value matching and role-based permissions routing.

### 2. Functions & Callbacks
- **Standard Functions:** Function declarations with default parameters (e.g., `taxRate = 0.05`).
- **Arrow Functions:** Concise syntax for single-expression and compact function signatures.
- **Callback Functions:** Passing functions as arguments to perform custom higher-order operations on collection data.

### 3. Iteration & Loops
- **Standard `for` Loops:** Index-based deterministic iterations.
- **`while` Loops:** Condition-driven iteration blocks (e.g., countdowns).
- **`for...of` Loops:** Clean, idiomatic modern iteration over iterable collections like Arrays.

### 4. Practical Exercises & Problem Solving
- **Grade Classifier:** Dynamic switch evaluation for numerical scores mapping to letter grades (A–F) with boundary handling.
- **Even/Odd Separator:** Filtering arrays based on numerical parity using higher-order logic.
- **Custom Array Transformer:** Building a custom mapping/transformation function using callbacks.
