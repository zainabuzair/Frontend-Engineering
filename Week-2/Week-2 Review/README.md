# Week 2 Frontend Engineering Revision Dashboard

An interactive dashboard built with vanilla JavaScript (ES6+), demonstrating core browser engineering concepts without external libraries.

## Features
- **Task Management**: Create, filter (All, Pending, Completed), and delete tasks.
- **LocalStorage Integration**: Persists task data across page reloads.
- **Form Validation**: Clean error handling and input sanitization on creation.
- **Async Data Fetching**: Retrieves external user data from `jsonplaceholder.typicode.com` using `async/await` and handling network errors cleanly.
- **Event Delegation**: Optimized DOM event listeners for list handling.

## Concepts Covered
- JavaScript Fundamentals (Scope, Control Flow, Data Structures)
- ES6+ Features (Arrow Functions, Destructuring, Spread Syntax, Template Literals)
- DOM Selection & Dynamic Node Manipulation
- Event Listeners & Event Delegation
- Web Storage API (`localStorage`)
- Asynchronous JS (`fetch`, Promises, `async/await`, `try/catch`)
