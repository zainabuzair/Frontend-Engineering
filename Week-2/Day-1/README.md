# Modern JavaScript (ES6+) - Day 1 Fundamentals

This repository contains my hands-on exercises for **Day 1: JavaScript Fundamentals**. 

## 📚 Topics Covered
- **Variables & Scope:** `let`, `const`, and legacy `var`.
- **Data Types & Type Conversion:** Primitives vs. Reference types, explicit conversion, and implicit coercion.
- **Truthy & Falsy Values:** Evaluating boolean contexts.
- **Template Literals:** String interpolation using backticks (`` `${var}` ``).
- **Arrays & Objects:** Methods (`.push()`, `.shift()`, `.filter()`), dot/bracket notation, and object methods.
