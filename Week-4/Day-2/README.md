# Day 2: TypeScript with React

## 📌 Topic Overview
This project demonstrates how to build a fully type-safe **React** application using **TypeScript** and **Vite**. It covers essential patterns for component props, state management, event handling, API fetching, generic typing, and reusable interface definitions.

---

## 🚀 Setup & Execution Instructions

### Prerequisites
- **Node.js**: v18+ (tested on Node v24)
- **Package Manager**: `npm`
